## 🛠️ LLM Algorithm Internship at Wenge AI (中科闻歌)

**ScienceOne S1-DeepResearch-32B** · Agent skill training across six key model capabilities

- **Open training data.** End-to-end responsibility for the skill-use portion of the released training dataset, from data collection and task design through trajectory generation, validation, and release. [Dataset on Hugging Face](https://huggingface.co/datasets/ScienceOne-AI/S1-DeepResearch-15k)
- **Skill and task design.** Collection, screening, and categorization of agent skills. Design of realistic user requests and supporting files, with relevant and distractor skills to train skill selection.
- **Trajectory generation.** Pipeline development for self-contained single-turn tasks, tasks that depend on file attachments, and multi-turn tasks that carry forward conversation history and workspace state.
- **Training data quality.** Rule-based validation and LLM review of execution traces to check task completion, instruction-following, and whether the agent applied the intended skill.
- **Model skill use.** Targeted training to improve skill selection, adherence to skill instructions, and tool and file use across single-turn and multi-turn tasks.

For more on this work, see the [S1-DeepResearch technical report](https://arxiv.org/abs/2606.15367) and the [S1-DeepResearch-32B model on Hugging Face](https://huggingface.co/ScienceOne-AI/S1-DeepResearch-32B).
